# Cyberpunk Portfolio — Phạm Khánh Linh

Responsive single-page portfolio created with HTML, CSS, and vanilla JavaScript. Open `index.html` in a modern browser—no build step is required.

The portrait is preserved at `assets/images/portrait.jpg`. Optional audio may be added to `assets/audio/ambient.mp3`; missing audio is handled safely. The contact form validates client-side and includes a marked integration point for a future email service or backend.
